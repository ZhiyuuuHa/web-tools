# 电网刷题界面规范

2026-10-24 · 适用题库练习（练习设置）、刷题、错题本、学习统计四个页面，以及登录、连接失败、空状态、完成页和两个弹窗。技术栈不变：原生 HTML/CSS/JavaScript，复用工具箱的 `global.css`、`main.js`、`.site-header`、`.button`、`.panel`、`.form-control` 和公共字体栈，不引入 UI 框架。

## 设计原则

1. **题干和选项是视觉中心**：最大字号、最充足的行高和留白；进度、收藏、题号、同步状态等辅助信息用小一号字和次要色。
2. **状态不只靠颜色**：每种作答状态都有文字或符号，并配合形状差异（实心/空心、双线/虚线、圆形/方形）。
3. **适合长时间学习**：低饱和中性底色；卡片只用 1px 边框、不加阴影；悬停不位移；动效只做颜色过渡。
4. **一套变量，两套主题**：组件只引用语义变量，深色模式只替换语义层。

## Token 层级

`design-tokens.css` 是唯一取值来源，分三层：

| 层 | 命名 | 说明 |
| --- | --- | --- |
| 原始值 | `--quiz-gray-*`、`--quiz-slate-*`、`--quiz-blue/green/red/amber-*`、`--quiz-space-*`、`--quiz-text-*`、`--quiz-leading-*`、`--quiz-weight-*`、`--quiz-radius-*`、`--quiz-duration-*` | 只在 tokens 文件内部引用 |
| 语义 | 公共名 `--color-*`、`--radius-*`、`--shadow-*`，以及 `--quiz-text-subtle`、`--quiz-*-soft`、`--quiz-*-strong`、`--quiz-on-*` 等 | 浅色写在 `:root`，深色写在 `html[data-theme="dark"], body.dark-mode`（main.js 两处都会设置）；公共组件随之换肤，不需要新类名 |
| 组件 | `--quiz-question-*`、`--quiz-option-*`、`--quiz-key-*`、`--quiz-explanation-*`、`--quiz-card-*`、`--quiz-action-bar-*`、`--quiz-switch-*` | 定义在 `body` 上，跟随当前主题；在 1023px、760px 断点覆盖 |

`style.css` 中的颜色全部引用变量（Windows 高对比模式使用系统色）；间距、字号、圆角优先使用对应变量。

- 行高：题干 1.7（手机 1.65），选项 1.65（手机 1.6），解析 1.8（手机 1.75），正文 1.6，标签 1.45，标题和按钮 1.3。
- 字重：正文 400；题干 500（靠字号突出，长题干不显得厚重）；按钮、标题、标签 600；品牌和关键数字 700。
- 进度、计数和表格数字使用等宽数字（`tabular-nums`）。
- 换行：题干、选项和解析使用 `text-wrap: pretty`，完成说明和连接提示使用 `balance`；界面文案中的数字不与标签、单位拆开（脚本按段输出，必要时使用不换行空格）。

## 形状、阴影、层级、动效

- 圆角：4px 标签和插图；6px 多选字母方块；8px 按钮、输入框、工具按钮、题号格；10px 选项、解析、开关卡；14px 卡片；18px 弹窗和手机底部面板；胶囊用于状态标签、计数和进度条。
- 阴影：卡片不用阴影，只用 1px 边框；弹窗用 `--shadow-lg`；固定底栏用向上的弱阴影 `--quiz-shadow-bar`。
- 层级：底栏 90，公共页头 100；弹窗使用浏览器原生顶层。
- 动效：颜色和边框过渡 120ms；开关、进度条、底部面板 180ms；缓动 `cubic-bezier(.2, 0, 0, 1)`。悬停不位移（覆盖公共按钮的上浮效果）。遵循系统“减少动态效果”设置。
- 请求锁定：请求期间控件仍会禁用，但禁用外观延迟 300ms（`--quiz-busy-delay`）才出现，快速请求不会让整页闪烁；恢复可用时立即生效。

## 组件状态

### 答案选项

非颜色线索：

- 字母键形状表示题型：圆形为单选 / 判断，圆角方形为多选。
- 实心键表示学习者选择了该项，空心键表示未选择。
- 已选择、正确、错选都带第二道内描边（双线）；漏选使用 2px 虚线。
- 判定后，每个相关选项都有文字标记。

| 状态 | 条件 | 外观 | 非颜色线索 |
| --- | --- | --- | --- |
| 未作答 | 默认 | 表面底，1px 控件边框，空心字母键 | 无标记 |
| 悬停 | 仅鼠标设备 | 边框加深，浅灰底 | — |
| 键盘焦点 | `:focus-visible` | 2px 主色外描边 | 外描边 |
| 已选择（待提交） | 已勾选、未判定 | 主色浅底 + 双线主色边框，实心主色键 | 实心键、双线、“已选择”（桌面在行尾预留位置；手机为右上角小标签，选择时不重排） |
| 回答正确 | 正确且已选 | 绿浅底 + 双线绿边，实心绿键 | 实心键、“✓ 正确答案” |
| 正确答案（未选） | 单选 / 判断答错时的正确项 | 绿浅底 + 双线绿边，空心绿键 | 空心键、“✓ 正确答案” |
| 错选 | 选了错误项 | 红浅底 + 双线红边，实心红键 | 实心键、“× 错选” |
| 漏选 | 仅多选：正确但未选 | 琥珀浅底 + 2px 虚线 | 虚线、空心键、“✓ 正确 · 漏选” |
| 其余选项 | 判定后未选且非答案 | 文字和字母键降为次要色 | 无标记 |
| 背题 | 背题模式 | 答案项同“回答正确” | “✓ 答案” |
| 锁定 | 请求进行中 | 保持当前外观（已选择不丢失），光标为等待 | — |

Windows 高对比模式下，已选择、正确、错选使用系统色实线外描边，漏选使用虚线。

### 反馈与解析

- 反馈条：4px 左边条 + 浅底，首行加粗（“回答正确 ✓” / “回答错误 · 已记入错题本”），第二行为“正确答案：…”。
- 解析：弱表面块，小标题“答案解析”前有 3px 主色竖条；正文 16px / 1.8（手机 15px / 1.75）。
- 显示时机与旧版一致：提交后或背题模式显示，翻题不显示。

### 按钮

| 类型 | 默认 | 悬停（仅鼠标） | 按下 | 禁用 |
| --- | --- | --- | --- | --- |
| 主按钮 `.button--primary` | 主色底 + 对比色文字 | 主色加深 | 亮度 94% | 300ms 后 50% 透明 |
| 次按钮 `.button--secondary` | 主色浅底 + 浅蓝边框 | 主色边框 | 亮度 94% | 同上 |
| 安静按钮 `.button--quiet` | 表面底 + 控件边框 | 边框加深 + 浅灰底 | 弱表面底 | 同上 |
| 危险安静 `.button--danger-quiet` | 表面底 + 红字 | 红边框 + 红浅底 | 红浅底 | 同上 |

键盘焦点沿用公共 `:focus-visible`：2px 主色外描边。每个区域最多一个主按钮；题目判定后，“下一题”升级为主按钮。

### 其他组件

- **视图导航**：当前项为主色文字 + 600 字重 + 2px 下划线，其余为次要色；“错题本”旁显示错题数胶囊。
- **收藏**：“☆ 收藏本题” / “★ 已收藏”（`aria-pressed`），琥珀色只作辅助；手机只显示 ☆ / ★ 图标，完整文字保留给读屏。
- **题号格**：○ 未做（表面底 + 边框）、✓ 正确（实心绿）、× 错误（实心红）；当前题加 2px 主色外环。手机上题号列表为底部弹出面板。
- **背题开关**：滑块在左为关、在右为开；开启时整张开关卡变为主色浅底；焦点描边在卡片外。
- **练习设置**：标题右侧为“展开 / 收起”文字和箭头，收起时显示当前题库名。桌面收起后进入专注模式（880px 单栏居中）；手机开始练习后自动收起（沿用原逻辑）。
- **同步状态**：绿点“记录自动保存”，请求中为琥珀点“正在同步…”；未登录时不显示圆点。≤ 1023px 只显示圆点，文字保留给读屏；未登录时整体隐藏。
- **进度条**：4px 胶囊，主色表示进度。

## 页面应用

- **页头**（所有页面）：品牌、今日已答胶囊、同步状态、账号、退出、主题切换；320px 宽度下仍保持单行。
- **题库练习 / 练习设置**：桌面左侧为设置栏（当前题库、练习范围、学习方式），右侧为学习内容；范围统计按段换行，不拆开数字和标签。
- **刷题**：卡片顶部为轮次说明、收藏和题号进度，下方是 4px 进度条；再往下依次是题型标签、题号、章节（手机上章节独占一行且不截断）和作答状态，然后是题干、选项、反馈、解析。
- **固定底栏**：“上一题 / 提交答案 / 下一题”右对齐，单选和判断题不显示提交按钮。手机底栏左侧显示滑动提示，出现提交按钮时提示让位。页面底部按底栏实测高度留白，内容与底栏之间至少相隔 24px。
- **错题本**：摘要卡（标题、当前范围、开始错题练习）→ 规则说明 → 错题列表（题型、题号、“错题”标签、题干预览）→ 分页。
- **学习统计**：三张概况卡（≤ 1023px 改为紧凑横排）→ 题库完成度 → 题型统计表（新增“完成度”列）与最近答题（≥ 1280px 并排，记录在栏内滚动）→ 记录管理（题库来源和清空记录）。
- **其他页面**：空状态为三步引导；完成页为 ✓、结果句（按句换行）和后续操作；登录卡 400px；连接失败卡；确认弹窗；题号弹窗。

## 断点

| 宽度 | 变化 |
| --- | --- |
| ≥ 1280px | 统计详情两栏，最近答题在栏内滚动 |
| ≥ 1024px | 空状态三步引导排成三列 |
| ≤ 1023px | 侧栏 240px、栏间距 16px；同步状态只显示圆点；概况卡改为横排 |
| ≥ 761px | 收起练习设置即进入专注模式 |
| ≤ 760px | 手机：单栏、设置可收起、左右滑动翻题、题号底部面板、收藏只显示图标、题干 18px、选项和解析 15px |
| ≤ 380px | 底栏按钮缩小内边距和字号 |
| ≤ 360px | 页头间距收紧，今日已答胶囊省略“题”字 |

760px 与 `script.js` 中滑动翻题、自动收起设置的判断一致，修改时需两处同步。

## 使用规则

1. 新增颜色、间距或字号时，先在 `design-tokens.css` 中定义（颜色要同时给出浅色和深色语义值），组件只引用变量。
2. 新增状态必须同时有文字、符号或形状上的差异，不能只换颜色。
3. 悬停样式写在 `@media (hover: hover)` 中，避免触屏点击后残留。
4. HTML 中不写内联样式、内联脚本或事件属性（项目检查会拒绝）；动态数值通过 CSS 变量传入，例如完成度条的 `--value`。
5. 请求锁定规则保持在 `style.css` 末尾，确保覆盖各组件的过渡设置。
