# 电网刷题

支持公共与行业知识（2027 版，832 题）、天行电力计算机基础（1910 题）和计算机冲刺（2295 题）。公共题库来自用户提供的 PDF；计算机题库由用户已购小程序会话读取，仅收录对应两套题库的题目、原答案、解析及插图。

2026-10-22 按“科目错序练习”的完整题目列表补入基础库遗漏的 82 题：计算机网络现共 250 题，信息新技术现共 186 题。新增题按知识点归入对应章节，保留原有 1828 道题的内容、编号和章节。详见 `QUESTION_SUPPLEMENT_20261022.md`。原 `import_tianxing.py` 对应首次采集的章节清单，不能直接用旧清单重新生成并覆盖当前补全后的题库。

页面可切换题库，按科目、章节、单选、多选全选/非全选、判断对/错筛选；支持顺序练习、随机练习、继续进度、错题复习、收藏和背题。不同账号、不同题库分别保存记录和收藏，切换题库后可继续原来的练习。

页面复用工具箱样式，记录服务只依赖 Python 3 标准库与 SQLite。账号和密码按用户要求简单存储，建议使用专用密码。登录凭据有效期 30 天，退出登录时失效。

新版 UI 已于 2026-10-24 发布到原入口：http://110.42.223.114/tools/grid-quiz/index.html 。账号和刷题进度继续保留。

## 界面与设计规范

章节名称在界面中省略末尾“/ 练习题”（2026-10-24）；内部章节值保持原样，筛选和已有刷题进度不受影响。

2026-10-22 统一改版：同一入口内提供“题库练习、错题本、学习统计”三个视图。题库与筛选设置在桌面左侧展示，手机上可收起；开始练习或恢复已有轮次时，手机自动收起设置。切换视图只显隐内容，保留当前题的未提交选择；刷新后仍按原规则恢复服务器已保存的进度。

2026-10-24 新版界面：按 `DESIGN_SYSTEM.md` 重新统一颜色、字体、间距和组件状态。选项字母键用形状区分题型（圆形为单选/判断，方形为多选），实心表示已选；已选择、正确、错选为双线边框，漏选为虚线，并分别标注“已选择”“✓ 正确答案”“× 错选”“✓ 正确 · 漏选”。题目信息分为题型、题号和章节，状态标签区分未作答、待提交、正确、错误和背题。桌面收起练习设置后进入单栏专注模式；手机题号列表为底部面板。题型统计增加完成度列，题库来源和清空记录移到学习统计的“记录管理”。请求超过 300ms 才显示控件禁用外观，快速同步时页面不闪烁。

题干和选项优先展示；主色为蓝色，未做题用中性灰白，正确用绿色、错误用红色，并保留文字或符号标记。原解析与本地插图继续在提交后或背题模式展示。手机题干 18px、选项和解析 15px，选项至少 48px 高；上一题、提交答案、下一题固定在屏幕底部，滚动时保持可用；页面按底栏实际高度预留空间，并适配手机底部安全区，不遮挡选项和解析。

手机在题目区域左滑切下一题、右滑切上一题，沿用按钮的跳题和补答规则，不自动提交答案。已选择但尚未提交时，手势会提示并保留选择，可先提交或主动用按钮跳过。竖向滚动、双指缩放、图片/表格/代码块操作、文字选择和屏幕边缘手势不用于翻题。背题同样支持滑动，仍不修改服务器练习进度。

翻题时题干已完整可见则保留滚动位置；题干在视口之外时，仅将新题题干移到顶栏下方，不回滚到页面标题和导航。按钮、手势及背题使用相同规则，键盘焦点继续移到题干。

顶部“今日已答”汇总当前账号全部题库在北京时间当天的实际提交次数，重复练习同一题按每次有效提交计数，背题、翻题和重复请求不计入。登录、刷新、提交、翻题和切换题库时更新；清空某题库记录后，该题库对应的今日提交也会移除。

错题本按当前筛选范围分页展示题干，每页 20 题；“开始错题练习”复用原有错题轮次规则。统计展示整库概况、已刷题目完成度、科目/章节题型统计及最近作答。

`design-tokens.css` 提供原始值、语义、组件三层变量，复用公共 `.button`、`.panel`、`.form-control` 和字体栈，只在本工具内应用。颜色、字体、间距、深浅主题和组件状态详见 `DESIGN_SYSTEM.md`。没有新增 UI 框架、后端接口、URL 路由或数据库结构。

## 本地运行

从项目根目录执行：

```text
python tools/grid-quiz/server/app.py
```

打开 http://127.0.0.1:8765/tools/grid-quiz/index.html ，使用已有账号登录。注册功能已关闭，按钮置灰，注册接口返回 403。

默认数据保存在用户目录 `.web-tools-grid-quiz/quiz.sqlite3`，可通过 `--data-dir` 指定。不要将数据库放在静态托管目录。纯静态托管不提供记录服务，页面会显示服务器入口。

```text
python -m unittest discover -s tools/grid-quiz/server -p "test_*.py" -v
npm test
```

## 数据与规则

- 单选、判断点击选项即提交，随后显示结果与解析，仍需主动切换下一题；多选继续手动提交。同步期间选项暂时锁定；提交失败保留选择并显示提交按钮，便于重试。
- 每个账号在每套题库中保存独立的答题历史、当前轮次的题目顺序、已提交答案和当前浏览位置；服务器重启后可以恢复。刷题支持上一题、下一题和跳过后补答，翻题本身不计为作答；已提交的题目可回看答案。
- 开始新一轮会替换当前轮次，但保留历史和错题。随机一轮遍历筛选范围且不重复。
- 多选答案必须精确匹配，少选、多选都算错。错题本依据每道题最近一次作答更新，答对即移出。
- 题型统计随科目、章节变化，显示题目总量、已刷题目、当前错题；细分项已包含在主分类中，不能重复相加。累计正确率按当前题库全部作答次数计算。
- 点击题目右上角的“☆ 收藏本题”可收藏，再点“★ 已收藏”可取消；刷题和背题模式均支持，不会提交答案或清除未提交的选择。收藏按账号、题库独立保存，重新登录后仍可恢复。“只刷收藏／只背收藏”按当前科目、章节、题型筛选，显示对应收藏数量。已开始的收藏练习保留本轮题目，取消收藏从下一轮生效。
- 清空答题记录只清除当前账号、当前题库所有章节的历史、错题和轮次，保留收藏，不影响其他题库及其他账号。
- 请求重复提交不会重复记录；另一设备启动了新一轮时，旧轮次提交会被拒绝。
- 公共题库保留原编号和 PDF 页码；计算机题库使用各自的连续显示题号，同时保留来源题目 ID。收录原答案，不自动更改题库内容。
- 例外：冲刺库原题 ID `313049` 未标正确选项，经用户明确确认，依据原解析补全为“正确”。该题解析中注明补全原因，原始采集响应不变。
- 点击题目右上角的进度可查看本轮全部题号并点击跳转，按原题号排列；灰白表示未做、实心绿色表示正确、实心红色表示错误，蓝色描边标记当前题。分类依据当前账号最近一次作答，同时显示各类数量；刷题和背题模式均可跳转。最后一题之后若仍有漏题，会返回首个未作答题目，全部提交后才能查看本轮结果。
- 开启“背题模式”后直接高亮并显示正确答案，支持上一题、下一题及按筛选范围顺序、打乱、只背错题。浏览不会提交答案或改变答题统计、错题和服务器练习进度；关闭后返回原练习。背题浏览位置仅保留在当前页面中。
- 切换题库时，在当前页面内存中复用已加载的题库内容，只向服务器同步最新账号进度；题库内容版本改变时自动重新下载。刷新或关闭页面后重新加载。首次加载支持 gzip 压缩，每次切换仍验证登录状态，答题记录不使用缓存。

`server/import_pdf.py` 是这份 PDF 专用的转换程序，转换时需要安装 `pypdf`，运行网站不需要。重新导入会校验 1–832 连续编号、选项与答案有效性以及判断题的选项。

`server/banks/*.json` 加载附加题库；`server/import_tianxing.py` 离线转换本机已采集的题目响应，不处理登录凭据、不请求题库 API。导入校验两套题库的数量、重复 ID、答案和题型，移除外部 HTML 中的脚本及事件属性，把插图保存到 `media/`。页面再次过滤富文本，只显示允许的标签及本地插图。

旧数据库启动时自动将原记录归属公共题库：原轮次、已答题目和浏览位置保留。迁移前应进行 SQLite 在线备份。附加题库 JSON 仅通过登录后的题库接口读取，静态文件入口不提供服务源码或题库 JSON。

## 服务器部署

服务器目录 `/opt/web-tools-grid-quiz`，数据目录 `/var/lib/web-tools-grid-quiz`，服务名 `web-tools-grid-quiz`。服务使用独立低权限系统账号，监听 80 端口，开机自动启动。只发布本工具及公共样式脚本；服务器 `/index.html` 返回现有 GitHub Pages 工具箱。

```text
sudo systemctl status web-tools-grid-quiz
sudo systemctl restart web-tools-grid-quiz
sudo journalctl -u web-tools-grid-quiz
```

备份请使用 SQLite 在线备份接口，或先停止服务再复制完整数据目录（包含 WAL 文件），不要仅复制运行中数据库主文件。部署代码或更新题库不删除数据目录。
